
# Windows PC BSOD Troubleshooting

## 📌 Project Overview

This project documents my experience troubleshooting a Windows Blue Screen of Death (BSOD) issue.

The computer displayed a BSOD with the error code `0xc0000221`. I investigated the issue by reseating the RAM sticks and successfully restored the computer to a working condition.

## 🎯 Objectives

- Troubleshoot a Windows BSOD
- Identify and document the displayed error code
- Practice basic hardware troubleshooting
- Reseat RAM modules correctly
- Verify whether the troubleshooting resolved the issue

## 🛠️ Tools & Technologies

- Windows
- Desktop PC hardware
- RAM (Memory Modules)
- Hardware Troubleshooting

## ⚠️ Problem Description

### Error Code

`0xc0000221`

The computer displayed a BSOD with the error code above.

The exact underlying cause was not independently confirmed.

## 🔧 Troubleshooting Process

### 1. Problem Identification

I observed a BSOD on the computer displaying error code `0xc0000221`.

### 2. RAM Reseating

I removed two RAM sticks from their original slots.

I then installed the RAM sticks into the slots previously occupied by the removed modules.

### 3. System Verification

After reseating the RAM, I tested the computer and confirmed that the issue was resolved.

## ✅ Results

The BSOD issue was resolved after reseating the RAM sticks.

The troubleshooting demonstrated how checking and reseating internal hardware can be part of diagnosing computer stability issues.

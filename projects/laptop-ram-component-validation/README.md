# Laptop RAM Component Validation

## Overview

Tested an 8 GB laptop RAM module removed from an Acer Nitro 5 AN515-55 by installing it into an HP Victus 15.

The purpose was to isolate the RAM from the Acer's hardware failure and determine whether the module could function independently.

## Objective

Determine whether the Acer Nitro 5's 8 GB RAM module was functional by testing it in another compatible laptop.

## Procedure

1. Powered down and prepared the Acer Nitro 5 for hardware removal.
2. Removed the 8 GB SO-DIMM RAM module.
3. Installed the RAM module into an HP Victus 15.
4. Powered on the HP Victus.
5. Checked whether the system recognized the installed memory.
6. Used the second laptop as an independent test platform.

## Troubleshooting Concept

This is an example of **component isolation**.

Instead of assuming that the RAM was responsible for the Acer Nitro 5's failure, the component was tested independently in another system.
